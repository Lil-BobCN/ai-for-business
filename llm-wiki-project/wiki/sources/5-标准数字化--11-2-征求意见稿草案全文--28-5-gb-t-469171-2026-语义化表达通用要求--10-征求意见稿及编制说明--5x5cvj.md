## 术语定义（第 3 章，逐字保留）

- **3.1 语义 semantics**：语言所表达的意义或含义。
- **3.2 标准内容语义化 standard content semanticization**：将标准内容转化为具有语义关联关系且便于计算机理解和处理的数据或知识的过程。
- **3.3 表达单元 expression unit**：针对标准文献内容，不同类型标准所具有的且具有语义关联关系的数据。注：表达单元包括通用语义化表达单元和专用语义化表达单元。
- **3.4 标准语义知识库 standard semantic knowledge base**：用于存放标准内容语义化表达单元对应数据的载体。
- **3.5 标准化对象 object of standardization**：需要标准化的主题。[来源：GB/T 20000.1—2014，3.2]

## 第 10 章 存储要求（逐字保留）

**10.1 存储字段类型**：应包括字符串、数值、日期、时间、文本等，应符合以下规定：

```
a) 字符串字段：用于存储定长字符串和变长字符串；
b) 数值字段：用于存储整数和实数；
c) 日期字段：用于存储日期类型数据；
d) 时间字段：用于存储时间类型数据；
e) 文本字段：用于存储文本中的句子和段落。
```

**10.2 存储方式**：

```
a）标准内容语义化表达单元及其内容数据应按照上述表格顺序（见表3~表10）依次装入数据库；
b）将内容数据映射到标准内容语义化表达单元数据库；
c) 同一数据库可存储多种格式的内容数据，不同记录(行)的内容数据的格式可不同；
d) 同一条记录可存储一个或多个内容数据，同一条记录(行)中多个内容数据的格式可不同。
```

**10.3 存储介质与安全**：数据库应存储在机械硬盘和固态硬盘等存储介质上，应在不同的存储介质之间转移。数据库应保存在安全的存储系统中和存储介质上，防止被非授权改动数据库存储位置的设置，并保障数据不被非授权修改、访问、删除、复制和破坏，对授权修改、访问、删除和复制要做审计跟踪。涉密数据在线存储应加密，涉密数据导出和备份应采取数字签名等安全措施。

**10.4 存储信息管理**：

```
a）存储数据的基本信息（如存储时间、存储人员等），应能溯源数据修改、删除等操作；
b）存储过程中出现的问题或错误的信息；
c）存储数据跨系统、跨版本的存储数据逻辑应一致，无冲突；
d）针对关键数据（如指标数据）应进行人工复核。
```

## 主要论点（来源作者提出，证据状态 unknown/partial）

1. 标准内容语义化表达是标准语义知识库构建和标准数字化转型的基础环节；语义化是打通语法到语用的关键环节（编制说明）。
2. 语义化表达模型由两部分构成：语义化表达单元模型的构建 + 语义化表达规则的确立（第 5 章）。
3. 表达单元模型分两类：通用（题录类，各类型标准共有）与专用（主体内容，各类型标准特有）。
4. 通用单元分必备单元与可选单元，依据 GB/T 22373—2021（表 1）。
5. 专用单元按八类标准划分（术语、符号、分类、试验、规范、规程、指南、评价），依据 GB/T 20001.1～20001.8 及 GB/T 20001.10—2014。
6. 存储要求：字段类型五类、按表 3–10 顺序装入数据库、介质安全与审计跟踪、关键数据人工复核。
7. 编制说明主张：本标准填补了标准内容语义化缺乏相关标准指导的空白；国际、国外暂未发布相关标准。
