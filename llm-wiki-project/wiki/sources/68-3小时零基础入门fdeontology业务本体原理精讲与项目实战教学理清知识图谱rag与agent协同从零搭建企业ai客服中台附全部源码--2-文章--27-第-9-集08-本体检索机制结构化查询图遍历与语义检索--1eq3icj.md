## 一句话摘要

视频作者在这一集里把话题从"怎么把零散业务数据建成本体"推进到"建好的本体怎么被用起来"，围绕一份 `.owl` 的电商订单客服本体，讲清三种主流的本体检索策略——结构化查询、图关系查找、语义检索加图扩展，并说明它们在什么条件下该被选用、又如何落到 Agent、RAG 与人机回环（Human in the loop）的组合链路上。

## 主要论点（均归属视频作者木羽Cheney，`unknown / 待外部核验`）

1. **本体对 AI 的核心价值是提供运行时上下文。** 作者主张上下文越精准，执行准确度越高；并进一步主张配了完善上下文后，1.5B 级模型也能处理相关问答任务。无对照实验，属经验判断。这是本集最强、也最需要外部核验的判断，已单列到 [[上下文质量与模型规模贡献待核验]]。
2. **存在三种主流本体检索策略，可互相组合。**
   - 结构化查询：自然语言 → 查询语句 → 图数据库 → 结果范围 → 模型作答；落到 Object / Properties / LinkType 三类 schema 要素。
   - 图关系查找：依赖对象间通过 Type 建立的关联，用路径检索 / 遍历 / 路径搜索解决多跳（如员工→项目→部门的最小两跳）。
   - 语义检索加图扩展：embedding 向量化 → 相似度召回候选集 → 图关系查找取 top-k → 沿图路径补齐下游信息。
3. **本体与知识图谱常被混淆，源于展示形态相同。** 作者区分：本体定义领域知识与业务规则，知识图谱负责知识编排与结构组织。属作者口径，非标准定义，已单列到 [[本体与知识图谱职责边界待核验]]。
4. **选型标准为单维"问题明确度"**：明确 → 结构化查询；多跳关联 → 图遍历；描述模糊 → 向量召回 + 图扩展。见 [[本体检索策略选型]]。
5. **高风险应用需 Human in the loop**：人工批准后 AI 才执行下游任务。见 [[工作流与人工介入]]。

## 教学示例数据（构造数据，非生产数据，原样保留）

结构化查询示例（RDF 三元组与过滤投影）：

```
A --关系--> B
A --关系--> C
B 得分 = 0.9
C 得分 = 0.4
D 得分 = 0.95
过滤条件：得分 >= 0.8
结果：A 关联 B，B 得分 0.9（C 被淘汰）
```

图遍历示例（BFS 队列式扩展）：

```
初始化：A 入队
弹出 A → B、C 入队
弹出 B → D 入队（队列：C、D）
弹出 C → E 入队（队列：D、E）
弹出 D、E
结果：取首次发现路径为最优结构路径（无权图假设）
```

## 内部张力与缺口

1. **评测被提出但未被回答。** 作者把"人工参与后效果评测是什么样"列为今天要谈的核心基本理论之一，但本集实际未展开评测环节。
2. **三种策略可组合，但失败路径未讨论。** 结构化查询翻译失败是否回退向量召回？向量召回错误时图扩展是否放大错误？演示链路中看不到兜底机制。
3. **检索质量上限由建模质量决定。** 若上一集本体本身有偏差，本集三种策略只是在偏差上加速；本集未回到建模校验。
4. **"首达即最优"仅在无权图成立。** 作者提到"无权图"与"多个最小路径"，但未讨论带权或带业务优先级的图。
5. **本体 / 知识图谱区分属作者表述。** 朗读稿自承是"初步介绍"口径，不应直接当结论引用。
