## 二、内容结构

### 第8章 标准内容通用语义化表达单元构建与表达规则

- **8.1 确定依据**：根据 GB/T 22373—2021 的有关规定，确保通用语义化表达单元适用于不同类型标准内容语义化表达，应实现其在各行业和领域间具有较好的通用性和适用性。
- **8.2 确定步骤**：8.2.1 分析与识别 → 8.2.2 分类与归纳（合并同类项）→ 8.2.3 验证与调整（标准数据加工验证）。
- **8.3 说明**：给出表2，共 **48 项**通用语义化表达单元，含中/英文名称、含义、取值范围、示例。
- **8.4 语义化表达规则**：通用单元之间通过“主从”关系或“同等”关系进行语义关联，形式为“标准号”+“中文标准名称”+“其他通用语义化表达单元1”+…+“其他通用语义化表达单元n”；通过唯一标签实现明确标识，关联关系应具备**双向性和可追溯性**。含示例1、示例2（均以 GB/T 22373—2021《标准文献元数据》为对象）。

### 第9章 标准内容专用语义化表达单元构建与表达规则

- **9.1 确定依据**：应按照 GB/T 20001.1～20001.8 以及 GB/T 20001.10—2014 中相应部分的规定，结合每种类型标准的适用场景和独有内容提出。
- **9.2 确定步骤**：9.2.1 分析与识别 → 9.2.2 分类与归纳（按相似主题和单元结构聚类）→ 9.2.3 验证与调整（并可根据行业特点调整，见附录A）。
- **9.3 说明**：给出表3–表10，覆盖八类标准。
- **9.4 表达规则**：9.4.1 表达顺序性；9.4.2 语义完整性（含正反例与示例1、示例2）。

## 三、关键结构化数据（逐字保留）

### 第10.1条 存储字段类型

```
a)字符串字段：用于存储定长字符串和变长字符串；
b)数值字段：用于存储整数和实数；
c)日期字段：用于存储日期类型数据；
d)时间字段：用于存储时间类型数据；
e)文本字段：用于存储文本中的句子和段落。
```

### 第10.2条 存储方式

```
a）标准内容语义化表达单元及其内容数据应按照上述表格顺序（见表3~表10）依次装入数据库；
b）将内容数据映射到标准内容语义化表达单元数据库；
c)同一数据库可存储多种格式的内容数据,不同记录(行)的内容数据的格式可不同；
d)同一条记录可存储一个或多个内容数据,同一条记录(行)中多个内容数据的格式可不同。
```

### 第10.3条 存储介质与安全

标准内容语义化表达单元数据库应存储在机械硬盘和固态硬盘等存储介质上，应在不同的存储介质之间转移。数据库应保存在安全的存储系统中和存储介质上，防止被非授权改动数据库存储位置的设置，并保障数据不被非授权修改、访问、删除、复制和破坏，对授权修改、访问、删除和复制要做审计跟踪。涉密数据在线存储应加密，涉密数据导出和备份应采取数字签名等安全措施。

### 第10.4条 存储信息管理

```
a）存储数据的基本信息（如存储时间、存储人员等），应能溯源数据修改、删除等操作；
b）存储过程中出现的问题或错误的信息；
c）存储数据跨系统、跨版本的存储数据逻辑应一致，无冲突；
d）针对关键数据（如指标数据）应进行人工复核。
```

## 四、主要论点

1. **通用单元应跨行业通用**（8.1–8.3）：依据 GB/T 22373—2021，通用语义化表达单元须在各行业领域间具备通用性和适用性，通过“分析识别→分类归纳→验证调整”三步确定，最终形成表2的48项通用单元。
2. **专用单元按标准类型分化**（9.1–9.3）：依据 GB/T 20001.1～20001.8 及 GB/T 20001.10—2014，结合各类型标准适用场景，提炼八类专用单元（表3–表10）。
3. **语义关联具双向可追溯性**（8.4）：通用单元通过“主从”或“同等”关系关联，形式为“标准号+中文标准名称+其他单元1+…+其他单元n”，通过唯一标签标识，具双向性与可追溯性。
4. **专用单元表达须满足顺序性与完整性**（9.4）：按表3–10顺序排列（可依侧重点调整）；语义完整性要求覆盖概念/实体/关系/属性，复杂内容可分解为多级子单元。
5. **存储要求**（第10章）：字段类型五类；存储方式四条；介质与安全要求；信息管理四条（含关键数据人工复核）。
6. **行业适配**（附录A）：未按 GB/T 1.1—2020 起草的行业标准（如工程建设）无法完全遵守本文件规定，需通过行业专用模型适配；工程建设标准技术内容统一划分为“要求单元”和“措施单元”。

## 五、证据强度评估

- **强**：第8–10章及附录A的条款文本、表2–表10及表A.1的单元清单，均为标准正文直接还原，结构完整。
- **弱/待核验**：文本还原为自动过程未校对；表2存在明显重复项（序号26/41）与格式错乱（如“202305110”疑为“20230511”）；部分英文名称拼写异常（如“proposor”“mirror body”）；附录A末尾“10.5”标题残缺（“《标准语义知识库第部分：标准内容语义化表达通用要”）。
