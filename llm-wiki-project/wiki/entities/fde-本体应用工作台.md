# FDE 本体应用工作台

FDE 本体应用工作台是视频作者木羽Cheney 在 [[fde-ai-应用开发实战课]] 第二场直播中提供的项目源码，用于把已构建的本体文件接入 AI 问答与自动化工作流。它把本集讲解的检索路径与接入 Agent 的业务流程集成在同一个项目里，并配套一份电商订单客服本体做客服场景演示。

## 定义与来源观点

视频作者在该集口播中提出，这个项目源码可以在助教老师处领取，项目内集成了本集要讲解的知识点、核心检索路径以及接入 Agent 的业务流程。作者称项目里包含"本体检索实验室"，用于基于构建出来的本体提出针对性问题，并已把结构化查询、基于图的关系遍历、语义检索与图扩展三种方式集成到系统中。

## 项目分析

### 本体检索实验室

作者描述该模块用于"基于本体提出针对性问题"，并固定展示四类结果信息：

1. 当前实体的基本信息；
2. 该实体直接关联的对象；
3. 来源依据；
4. 整个处理过程。

这四要素可作为评估任何图检索演示界面是否合格的界面清单。

### 三条检索链路

项目集成了三条链路，与三种检索策略一一对应：

- 结构化查询：输入业务单号 → 运行检索 → 先找到订单 → 再找到对应链路的包裹；
- 图关系遍历：查业务订单 → 扩展到外链的所有本体核心链路关系 → 检索出订单来源、直接关联对象、关联实体类型、来源依据与处理过程；
- 语义检索加图扩展：链路形态与上两者一致。

### 客服场景演示

作者称结合电商领域本体文件，真实演示了把它做成客服类场景时，应用如何与 Agent 协同，为企业落地项目提供服务。

## 反例或边界

- 作者在公开课中未详细展开语义检索加图扩展链路的演示细节。
- 演示中看不到三种策略组合时的失败兜底机制。
- 项目源码与界面截图的真实性、可运行性未独立核验。
