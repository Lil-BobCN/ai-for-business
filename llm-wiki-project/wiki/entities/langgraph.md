# LangGraph

LangGraph 是本集视频作者用于订单客服 Agent 编排和工具调用链路的框架名称。本页只记录来源中的定位；演示所用版本、状态图和运行能力尚未独立核验。

## 来源中的定位

作者描述客服页面收到用户问题后，由 LangGraph 构建 Agent 编排，并借助其 tool calling 能力接入本体检索服务。订单演示的步骤被描述为订单定位、关联事实查询、状态查询、规则校验和回复生成。

## 项目分析

若把该演示抽象为工作流，至少需要维护：

- 当前订单和商品对象；
- 已调用工具及其参数；
- 查询返回的事实和来源；
- 规则校验结果；
- 是否需要人工介入；
- 最终回复以及回复前的审计记录。

这些是对演示链路的工程化分析，不是来源证明的 LangGraph 内置能力清单。

## 边界与待核验项

来源没有提供状态图代码、节点定义、依赖版本、工具 schema、重试策略、持久化方式或异常处理。也没有证明订单演示支持拆单、多个订单匹配、状态冲突、人工审批或失败恢复。

需要核对：

- Agent 状态图和节点之间的状态传递；
- tool calling 的实际参数和返回契约；
- LangGraph 与 Semantica 的集成边界；
- 工具失败、规则失败和人工介入的状态表示；
- 运行日志是否记录对象、工具、参数和来源。
