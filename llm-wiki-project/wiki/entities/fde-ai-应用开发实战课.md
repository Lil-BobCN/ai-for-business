# FDE AI 应用开发实战课

FDE AI 应用开发实战课是一门围绕企业 AI 应用交付的课程。本集作者将其体验营描述为两天安排，并介绍从 FDE 岗位认知、本体概念到订单客服业务建模的学习路径；本页记录来源中的课程介绍，不对课程效果或商业承诺作独立确认。

## 第 2 集：两天体验营导学

作者把第一天的内容安排为 FDE 岗位介绍、Ontology 与相关概念讲解，以及基于企业订单客服资料构建业务模型；第二天计划将当天构建的模型接入 Agent 和 RAG，用于订单处理服务。作者还以主商品和赠品分包裹发货的客服问题说明实战场景。

这段导学没有提供后续课程的实现材料，不能据此确认模型、Agent 或 RAG 已成功接入，也不能确认两天体验营与本页其他来源介绍的课程模块、课时和项目包装之间的对应关系。

## 来源中的课程结构

作者将课程描述为覆盖以下主题：

- AI 编程和 Agent 协作开发；
- 业务需求分析和方案设计；
- 企业知识治理、RAG、GraphRAG、Microsoft GraphRAG 与 Ontology；
- Agent 设计模式、workflow、skills、单 Agent 和多 Agent；
- 项目评测、部署、上线和迭代；
- 企业项目和综合结课项目。

作者还把零基础学习路径概括为业务理解、驾驭 AI、技术选型、知识治理和业务建模五个阶段。

## 来源中的项目和交付物口径

视频出现的课程口径包括：

- 60 小时或 60+ 小时；
- 六个阶段或六大模块；
- 三个热门项目；
- 两个工业级复刻项目；
- 两个企业落地项目；
- 一个综合结课大作业；
- 一个 FDE 交付工作流；
- 12 个可复用 Agent；
- 6 项项目结果；
- 七个可写进简历的项目。

这些说法来自不同段落，课程阶段、项目数量和交付物之间的映射没有完整说明。项目数量可以按三加二加二加一理解为八个，但“七个简历项目”与结课项目的对应关系仍需核对。

## 来源中的服务与商业承诺

作者提到直播和录播、答疑群、课程长期观看、人工智能应用工程师报考渠道、项目源码和数据集等内容，也提到 FDE 岗位、薪资、接单和证书价值。

这些内容没有提供合同、课程页面、政策文件、证书发行主体、岗位样本或学员统计。它们应与技术教学内容分开评估。

## 项目分析

课程介绍中可提炼出的学习方法是：通过业务调研、需求拆解、数据治理、应用开发、评测上线和持续迭代，形成可迁移的交付工作流。这个方法与课程是否有效是两个问题，前者可以作为能力框架，后者需要学习成果和项目证据。
