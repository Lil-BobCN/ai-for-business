# 南网科研院

南网科研院（全称：南方电网科学研究院有限责任公司）是南方电网体系内的科研机构，在标准数字化相关国家标准的起草材料中以起草工作组或主要起草单位身份出现。

> **独立可核验背景**：南方电网科学研究院有限责任公司（简称“南网科研院”）是南方电网公司下属的科研机构。该身份说明属于公开可查的背景信息，不由 GB/T 46917.2-2026 编制说明（文本版）直接确立。

## 组织身份

- 简称“南网科研院”，全称“南方电网科学研究院有限责任公司”。
- 在 GB/T 48000.2-2026 的官方条目档案中，该院以“南方电网科学研究院有限责任公司”这一名称登记。
- 该院与 [[南方电网标准中台]] 的组织关系，所引来源未涉及。

## 起草参与情况

### GB/T 46917.2-2026《标准语义知识库 第2部分：数据接口要求》

依据来源：该标准编制说明（文本版）。

- 在该来源中，南网科研院作为起草工作组的牵头单位之一出现。
- 编制说明称，根据标准语义知识库数据接口实用化要求高、产业需求强的特点，成立了由**南网科研院、中国标准化研究院、华南理工大学**等产、学、研单位组成的起草工作组。
- 起草组自述中提到，南方电网在企业内部构建了标准语义知识库并构建“标准中台”，提供给电网设备全生命周期管理使用，作为行业实践案例被引用（该自述主体为南方电网，见 [[南方电网标准中台]]）。

### GB/T 48000.2-2026《标准数字化 第2部分：参考架构模型》

依据来源：该标准官方条目档案（[[5-标准数字化--6-1-标准档案--36-11-gb-t-480002-2026-标准数字化-第2部分参考架构模型--piadwu]]）。

- 主要起草单位之一：38 家主要起草单位名单中列有“南方电网科学研究院有限责任公司”。
- 该署名在档案的两组署名口径中均出现，仅括号等排版层面存在差异。
