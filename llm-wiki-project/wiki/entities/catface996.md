# catface996

catface996 是 B 站视频《Ontology：AI Coding 在本体中的建模和实战》（bvid `BV1wVb76bE8e`）的署名作者与口播人，也是该视频中自建 AI Coding 本体系统（[[entities/ai-coding-本体系统]]）的演示者。本页仅记录该来源可归属到该作者的主张，不涉及其身份的其他公开信息。

## 来源观点（均归属 catface996，`unknown / 待外部核验`）

- 提出"语义跨度 × 可形式化验证"作为 AI Coding 可靠性的两个核心变量（见 [[concepts/语义跨度]]、[[concepts/可形式化验证]]）。
- 提出"数据—信息—知识—判断"四层框架（见 [[concepts/数据-信息-知识-判断四层框架]]）。
- 主张面向制品而非面向角色的拆解方式（见 [[concepts/面向制品与面向角色]]）。
- 提出成功率连乘模型与单步确定性要求（见 [[concepts/成功率连乘与单步确定性]]）。
- 提出强制力四层排序（见 [[concepts/强制力四层排序]]）。
- 主张神经符号（Neuro-symbolic）作为解法方向（见 [[concepts/神经符号]]）。
- 演示其自建本体系统，并给出规模数字（约 70 个 class、23 个拓扑子图、25 个 command 等），作者自述数据"可能已过时"。
