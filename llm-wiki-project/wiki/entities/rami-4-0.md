# RAMI 4.0

RAMI 4.0（Reference Architecture Model of Industry 4.0，工业 4.0 参考架构模型）是德国于 2015 年提出的工业领域参考架构模型，用于定义工业 4.0 的最重要方面，并为未来各相关方开展工作提供活动管理和规划的工具。**该身份说明属于可独立核验的公开背景知识，不来自本来源文件。**

## 来源观点

在 GB/T 48000.2-2026 编制说明中，起草组将 RAMI 4.0 列为参考架构模型（RAM）的典型先例之一，并作为本标准第 8 章**应用层级维度**的主要参考对象之一（与 IEC SAM 并列）。起草组同时指出，我国的智能制造体系架构与 RAMI 4.0 模型存在差异，需要结合我国国情进行本土化研究——这一差异被列为 SAM 模型在我国适用性有待论证的例证之一。
