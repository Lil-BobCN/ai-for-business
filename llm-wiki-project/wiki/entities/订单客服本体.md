# 订单客服本体

订单客服本体是视频作者木羽Cheney 在 [[fde-ai-应用开发实战课]] 第一场直播中构建、并在第二场直播中作为检索输入使用的电商领域业务本体。它以 `.owl` / RDF 形式交付，覆盖客户、订单、包裹与物流等业务对象及其关联关系，是本系列"建模 → 调用"链路的连接点。

## 定义与来源观点

视频作者在该集口播中回顾：上一节课已经建好了一份基于订单的电商客服本体，把关联的客户、订单、包裹以及物流信息都构建成了知识图谱，可以理解成一份可用的业务模型或本体的业务模型。本集所有检索演示都以这份文件为输入。
