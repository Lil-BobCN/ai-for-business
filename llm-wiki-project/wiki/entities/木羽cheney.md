# 木羽Cheney

木羽Cheney 是「3小时零基础入门FDE」系列课程与口播文章的作者，也是该系列中关于 FDE 岗位、Ontology 业务本体、RAG 与 Agent 协同等主张的归属主体。本 Wiki 中凡引用该系列观点，均以「视频作者在该段口播中提出……」的方式标注归属。

## 来源观点

- 在本集（第 5 集｜04-业务本体入门）中，作者以电商订单客服「跨系统往返查询又慢又易错」为痛点，论证 FDE 现场交付必须构建业务本体（Ontology），并把它定位为 Agent 统一的上下文查询与推理入口。
- 作者给出本体三要素 objects / properties / links，并用一张电商关系网与「主机到了、奶泡壶呢」的完整问答链路做演示。
- 作者主张上下文补齐后，千问 3B / 1.5B 等小模型也能回答问题，把瓶颈从模型能力转移到上下文供给。
- 作者给出非编程背景切入 FDE 的三步学习路径：AI 编程基础 → 需求拆解 → 技术架构选型。
- 作者在口播中推荐 codex、Claude Code、cursor、DeepSeek Harness 等 AI 编程工具，并称其团队内部实际使用 codex。
