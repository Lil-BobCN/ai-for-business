# MySQL

MySQL 是一种开源关系型数据库管理系统，属于公开可独立核验的背景知识。视频作者在《第 3 集｜一口气讲透大数据、数据库、数据仓库、数据湖、数据中台的底层原理》中把 MySQL 作为"业务数据库/在线交易库"的代表反复引用。

## 定义

视频作者在该段口播中把 MySQL 与 Oracle、PostgreSQL 并列，作为"专门管理数据的系统"的代表，称它们干的都是同一类活：把数据按表来组织，一行一条完整记录，一列一个属性，采用行式存储，适合对单条数据的增删改查。

## 来源观点

作者在八步电商流程中把 MySQL 放在第 1 步：用户点击提交订单，数据写入 MySQL 数据库，毫秒级完成。作者还提出，MySQL 这类业务数据库是大数据体系的上游数据来源，属于"存"这一环节中热数据的存储位置。

## 已核验事实

无。本集仅把 MySQL 作为举例引用，未提出关于 MySQL 的独立技术主张；本集给出的"毫秒级完成"为作者口播描述，`unknown / 待外部核验`。

## 项目分析

MySQL 在本集叙事中承担"管当下"的角色，与 [[concepts/交易与分析分离]]、[[concepts/行式存储与列式存储]] 直接相关：作者用它说明交易库不能拿来跑分析。本集未讨论 MySQL 的具体版本、存储引擎或部署形态。
