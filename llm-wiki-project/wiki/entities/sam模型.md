# SAM 模型

SAM 模型（Standard Architecture Model，标准架构模型）是 IEC/SMB/SG12 在《SMB/7326/R》报告中提出的标准架构模型。根据 GB/T 48000.2-2026（征求意见稿）引言的陈述，该模型包括标准内容的生命周期、能力等级、层级三个维度。

## 来源观点

来源（引言）称：IEC/SMB/SG12 在《SMB/7326/R》报告中提出了 SAM 模型（Standard Architecture Model），包括标准内容的生命周期、能力等级、层级三个维度，该模型提供了面向服务的标准化体系结构，为国际层面标准数字化活动开展建立了共识。来源并称国内 GB/T 48000.1 提出的过程数字化、内容数字化、应用数字化三个方面与 SAM 模型三个维度的内涵一致。
