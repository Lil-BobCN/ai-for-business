# IPVS

IPVS（IP Virtual Server）是 Linux 内核中的四层负载均衡技术实现，是 LVS 在内核态完成请求分发的执行组件。本页记录 [[架构师阿Q]] 第 5 集口播中对 IPVS 的描述。

## 定义

视频作者在该段口播中把 IPVS 描述为「基于 Linux 内核的四层负载均衡技术」，在 LVS 的 NAT 模式中由它执行目标 IP 地址的转换。

> 独立可核验背景（非本来源内容）：IPVS 是 Linux 内核自 2.4 系列起内置的负载均衡模块，通常与 ipvsadm 命令行工具配合使用。此句为公开可查的通用背景，不由本来源支持。

## 来源观点（`unknown / 待外部核验`）

- 视频作者在 NAT 模式一段中称：客户端访问 Director 时，基于 Linux 内核的四层负载均衡技术 IPVS 会把数据包的目标 IP 从 VIP 修改为后端 Real Server 的 RIP，完成目标 IP 转换。
- 作者未说明 IPVS 在 DR、TUN 模式中的具体作用，也未给出任何配置命令或内核参数。

## 项目分析

- 在本集叙事中，IPVS 是「LVS 工作在内核态」这一性能论断的技术落点：因为分发逻辑在内核中执行，作者据此认为其性能高于用户态的七层软件。
