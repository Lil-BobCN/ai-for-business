# Claude Code

Claude Code 是 Anthropic 推出的 AI 编码工具（此为可独立核验的公开背景信息，非本集来源所述）。在「零点未来：AI+企业」第 10 集中，它是 ABC Legal 业务人员实际用来搭建 Agent 的直接工具：员工复制公司提供的两种模板后，把需求讲给 Claude Code，即可生成可运行的 Agent。

> 归属说明：本页关于 Claude Code 在 ABC Legal 案例中的用法，均来自视频作者口播，属 `unknown / 待外部核验`。

## 来源观点（视频作者口播）

- 十五人委员会成员「自己去 Clone GitHub 仓库，用 Claude Code 来做 Agent」。
- 客户经理案例：把对流程的描述给到 Claude Code，一小时搭出每天自动交付的 Agent。
- 作者评价：这位客户经理「没有变成程序员，只是终于把自己脑中的业务流程变成了一个可运行的系统」。
