# Anthropic

Anthropic 是一家 AI 研究与产品公司（此为可独立核验的公开背景信息，非本来源所述）。在本 Wiki 中，该页目前仅记录「零点未来」系列视频对 Anthropic 的转述性引用，尚未有独立核验的一手材料。

## 来源观点（视频作者口播，`unknown / 待外部核验`）

视频作者在该段口播中提出，Anthropic 与「几十个团队」合作之后发现，所谓大道至简，最成功的实现几乎都没用复杂的框架，而是用简单和组合的一些模式。作者据此引出「只在值得的时候才做这笔交易」的立场。

作者还转述了 Anthropic 的三条铁律：

1. 保持简单——最成功的系统没有用复杂的框架；
2. 透明可解释——能解释、能展示 Agent 的规划步骤；
3. 精心打磨 Agent 和工具的接口，这个值得更多投入。
