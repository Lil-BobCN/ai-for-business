# 本体构建 Agent Skills

本体构建 Agent Skills 是视频作者木羽Cheney 团队内部使用、并在公开课中免费发放的一组三个 Agent Skill 技能包，用于把散落的业务资料逐步转化为标准 `.owl` 本体文件。作者称这三个 Skill 可以交给任意编程模型（例如 Codex、Claude Code）读取使用。

> 本页内容来自视频作者在该集口播中的介绍，属教学演示与经验性归纳，未经独立核验，证据状态为 `unknown / 待外部核验`。三个 Skill 的提示词原文与产物模板未在本集正文中展开。

## 三个 Skill 的职责划分

作者在该段口播中提出的分工如下：

| Skill | 职责 | 输入 | 产物 |
|-------|------|------|------|
| Ontology Design | 推荐当前业务场景下如何确定类型、属性和关系，明确边界、身份与约束；规定稳定的中文名称、抽取格式，匹配 OWL 语义 | 用户目标、已有建模要求、可用资料 | 可实施、可验证的本体方案（含建模与方案模板） |
| Ontology Extract | 按已确认的本体方案，从原始材料中提取有效知识 | 任意领域的原始材料与溯源文件 | 规范化后的知识模型结构 |
| Ontology Build | 把已明确的知识模型转化为标准本体文件 | 知识模型 | 标准 `.owl` 文件（含生成脚本） |

## 来源观点

- 作者称这三个 Skill 是"团队内部使用"的，公开课参与者可直接找助教老师领取。
- 作者称 Skill 包内有一个 `.agents` 目录，其中包含这三个 Skill 文件。
- 作者称 Design 的流程是"将用户要表达的知识整理成可实施、可验证的本体方案"，并在没有目标时识别覆盖范围、提出少量能影响建模的用途。
- 作者称每个阶段都有真实提示词原文与预期产物，参与者可复制提示词并配合 Skill 完成建模。

## 已核验事实

- 本集确实在口播中介绍了这三个 Skill 的名称与职责划分（来源：本集 ASR 转写，`partial`）。
- 除此之外，Skill 的具体内容、提示词原文、模板结构均未在本集公开，无法核验。

## 项目分析

把资深建模者的判断步骤封装成带流程、带输入约定、带产物模板的 Skill，是本集最可复用的工程化做法之一。它把"本体设计"拆成命名规范、边界判定、身份与约束三类可检查项。但"打包成 Skill 就能完成建模"隐含两个未验证前提：模型能可靠遵守流程，且业务方有人能判断输出对错。

## 反例或边界

- 若团队中无人能承担业务定义责任，Skill 输出的方案容易退化为"看起来合理"的通用模板。
- 本集未给出 Skill 在异构来源、数据敏感或体量更大场景下的表现证据。
