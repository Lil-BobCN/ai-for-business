# 国家标准全文公开系统

国家标准全文公开系统（域名 `openstd.samr.gov.cn`）是国家市场监督管理总局提供的国家标准正式文本在线阅读平台。用户可在其中按标准号或 `hcno` 参数查看已发布国家标准的正式文本；该系统也是提供国家标准正式发布版全文在线阅读的官方入口。

## 定义与入口

| 项目 | 内容 |
| --- | --- |
| 标准信息页 URL 形式 | `https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=<hcno>` |
| GB/T 47012.1-2026《标准数字化平台 第1部分：系统架构》全文入口 | `https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=73DA816822FDD33B1EEDDB84626F90AE` |
| GB/T 48000.2-2026《标准数字化 第2部分：参考架构模型》全文入口 | `https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=EAA7EFAD42BADBFFD3B54E2506D62811` |

- 在 GB/T 47012.1-2026 的官方条目档案中，该系统是正式发布版全文的获取入口，但本次未做抓取。
- GB/T 48000.2-2026 的官方条目档案记录：其正式文本在该系统提供在线阅读。

## 证据状态与约束

- 阅读页对页面图像做了**防批量下载处理**。
- 本次采集**没有绕过该处理**，因此只登记入口 URL、不保存正文；GB/T 47012.1-2026、GB/T 48000.2-2026 等条目的正式发布版全文均未抓取（未获取）。
- 来源据此将“正式发布版条款”标为 `unknown`，并明确约束：**不得**根据草案推断正式版条款内容。
- 正式发布版全文未获取。
- 本系统相关记述来自 GB/T 47012.1-2026、GB/T 48000.2-2026 的标准条目档案及检索记录来源。

> **证据约束**：正式版条款 `unknown`；草案内容不能用作正式发布版条款的替代引用。

## 在 Wiki 中的角色

- 该防批量下载限制是 [[标准正文获取三态]] 中“未获取”状态的直接成因之一；本系统是该状态（正式发布版全文未获取）的具名主体。
- 本系统在本 Wiki 中的核心作用是承载“正式版条款 unknown”这一证据约束，也是所有“正式版 vs 草案差异待核验”类开放问题的取证入口。
- 由于正式版全文不可批量获取，标准数字化系列标准的条款级判断目前只能基于公开征求意见稿；正式版与草案的差异构成核心知识缺口。

## 边界与反例

- 需要条款级引用或逐条核对条款时，应在该系统在线阅读或购买正式出版物，而不是引用征求意见稿。
- 本系统不提供元数据检索；元数据入口是 [[全国标准信息公共服务平台]]。
- 该系统与 [[中国标准在线服务网]]、[[全国标准信息公共服务平台]] 的功能边界，需更多来源补充。
