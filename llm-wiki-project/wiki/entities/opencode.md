# opencode

opencode 是视频作者 catface996 在《Ontology：AI Coding 在本体中的建模和实战》演示中使用的 coding 工具，通过 MCP 接入其自建本体系统（[[entities/ai-coding-本体系统]]），是"本体 + coding 工具"组合中的接入端。

## 来源描述（作者口播，`unknown`）

- 演示中作者使用 opencode 连接本体系统的 MCP，输入"使用 Ontology 来读取 AI Coding 的本体"来读取本体。
- 作者提到 opencode 会委派一个 subagent 去读本体详情，并把本体详情直接保存在一个文件里（作者称"不同的工具它的处理方式不太一样"）。
- 演示所用模型版本为 `DeepSeq WastePro`（待确认，ASR 识别存疑），经 OpenRouter 调用。

## 已核验事实

- 无。opencode 在本来源中仅作为演示接入工具出现，其自身能力、版本、开源状态均未在本来源中展开，也未做独立核验。

## 项目分析

本来源未对 opencode 本身展开，仅作为接入手段。其价值在于说明"本体系统如何被 coding 工具消费"这一环节。
