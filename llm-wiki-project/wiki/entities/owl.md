# OWL

OWL（Web Ontology Language）是本集讨论的一种本体表达语言。视频作者称它由 W3C 制定，并用它说明模型定义与实例事实的表达；本页仅记录该来源观点，不独立确认其标准归属或具体能力。

## 来源观点

视频作者把 OWL 描述为本体模型定义和实例事实的标准表达形式，并给出以下术语对应：

- 类型对应 `Class`；
- 数据属性对应 `DataProperty`；
- 对象关系对应 `ObjectProperty`。

作者认为采用标准表达可能有利于跨系统接入和复用，同时承认企业也可以建立内部标准。关于“无缝接入”、社区生态和标准成熟度的判断没有配套案例、版本信息或工具链对照，仍待核验。

## 能力边界

来源没有提供 OWL 文件、语言版本、约束配置、推理器、解析代码或运行结果。因此，不能据此认定某个 Agent 能读取或推理 OWL，也不能将文件可读取等同于支持全部语义、约束或规则执行。

`Class`、`DataProperty` 与 `ObjectProperty` 的具体含义及适用范围，应以可复核的一手标准资料和实际工具支持为准。
