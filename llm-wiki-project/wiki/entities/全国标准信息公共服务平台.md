# 全国标准信息公共服务平台

全国标准信息公共服务平台（域名 `std.samr.gov.cn`）是国家市场监督管理总局提供的标准检索与信息公共服务平台，面向国家标准信息检索与详情查询，提供标准检索入口、标准详情页以及“相近标准”等关联信息。在本次“标准数字化”资料采集中，它被视为国家标准、行业标准、地方标准等标准元数据的统一检索与查询入口。

## 平台角色

- **元数据真源入口**：在 GB/T 47012.1-2026《标准数字化平台 第1部分：系统架构》的官方条目档案中，本平台即为元数据逐字抓取的来源，抓取日期 2026-10-12；元数据由脚本逐字抓取，未做人工改写。
- 该平台是标准数字化系列标准元数据 `verified` 状态的主要来源。
- 本页记录的身份与接口行为，均来自本次采集脚本的实际调用结果。

## 检索入口与 URL 结构

| 用途 | URL |
| --- | --- |
| 检索入口页 | `https://std.samr.gov.cn/search/std?q=标准数字化` |
| 实际结果页 | `https://std.samr.gov.cn/search/stdPage?q=标准数字化&tid=` |
| 详情页（GB/T 47012.1-2026 条目档案所用示例） | `https://std.samr.gov.cn/gb/search/gbDetailed?id=49FD1852CAB9C31FE06397BE0A0A1304` |
| 详情页（GB/T 48000.2-2026 条目档案所用） | `https://std.samr.gov.cn/gb/search/gbDetailed?id=49FD1852CA42C31FE06397BE0A0A1304` |

来源指出，检索入口页本身**不渲染结果**，它是检索外壳页，结果放在页面内嵌的 iframe 中：

```html
<iframe src="https://std.samr.gov.cn/search/stdPage?q=标准数字化&tid=" id="myiframe" ...>
```

> [!note] 复现要点
> 复现检索结果必须使用 `stdPage` 结果页 URL，而不是入口页 URL。

GB/T 48000.2-2026 的官方元数据字段即来自其详情页的逐字抓取，可在该页直接复核。

## 接口行为与已核验事实

- 国家标准查询接口：`POST https://std.samr.gov.cn/gb/search/gbQueryPage`，表单字段 `searchText`；查询“标准数字化”命中 5 条。
- 统一结果页对“标准数字化”给出模糊关键词命中 17 条（抓取日期 2026-10-12）。
- 检索把“标准数字化”拆为“标准”“数字化”两个独立关键词，因此 17 条中 11 条为噪声命中。
- 标准元数据（标准号、名称、状态、日期、分类号、归口单位、起草单位、起草人）可在详情页逐一复核，来源将其标为 `verified`。

## “相近标准”与模糊关键词命中

- 平台还提供“相近标准(计划)”的关键词相似度匹配结果；GB/T 48000.2-2026 条目档案列出了 5 项跨领域标准，并明确声明该匹配**不代表内容引用或技术承接关系**。
- 该匹配机制是 [[模糊关键词命中与分词误命中]] 讨论的对象之一，需避免把关键词匹配误读为技术依赖。

## 项目分析

本平台是本次采集的元数据真源入口，也是后续所有标准条目档案的来源可追溯性基础。其接口与 URL 是复现检索结果的关键，因此被单独建页以便复用。GB/T 47012.1-2026《标准数字化平台 第1部分：系统架构》的官方条目档案，以及 GB/T 48000.2-2026《标准数字化 第2部分：参考架构模型》的官方条目档案，均以本平台作为元数据逐字抓取的来源。

## 边界与反例

- 本平台只提供元数据与检索，不提供正式发布版全文；正式版全文入口是 [[国家标准全文公开系统]]。
- 本平台不覆盖团体标准库（[[团体标准信息平台]]）与企业标准库。
- 本平台不覆盖国家标准计划库（在研项目）。
- 本平台与 [[中国标准在线服务网]]、[[国家标准全文公开系统]] 的功能边界，需更多来源补充。
