# OntoPrompt

OntoPrompt 是视频作者零点未来在该集口播中提到的、由他本人基于"直给派 + 约束规则"用 vibe coding 方式构建的一个 Ontology 构建小工具，用于从文档中提取实体与关系并生成知识图谱。**该工具名称按 ASR 还原，专名待确认。**

## 来源观点（作者口播，`unknown`）

作者称，为了帮助理解 Ontology 是什么以及怎么构建，他基于直给派——即 prompt 加上一些约束规则的方式——vibe coding 了这个工具，并加了一些抽取和验证的规则。

### 界面功能（作者演示描述）

- **左侧功能**：概览、本体管理、提示词管理、模型管理、设置。
- **设置**：可设置 LLM 读取文档过程中识别实体逻辑的置信度阈值（如 Action 最低置信度）；可选择性地开启 LLM 读取和验证规则，如多文档实体验证、本体质量验证等。
- **提示词管理**：可创建和编辑不同业务域的本体（如供应链、财务、营销），每个域有详细 prompt 模板。
- **本体管理**：可点击"创建本体"新建本体，选择业务域。
- **文件上传**：支持文本、Markdown、CSV 等多种文件类型；作者演示上传了 10 个文档。
- **模型配置**：可选择 prompt 模板并配置模型（作者演示使用 DeepSeek V4）进行提取。
- **知识图谱查看**：可选择层级或圆形等不同分布类型展示；演示中的主要实体类型为 `organization`、`product`、`document`、`facility`；可查看实体属性、关联实体及关联逻辑规则（如采购触发规则、对应 Action）。

作者称工具托管在 GitHub，可下载或 fork 体验。

## 项目分析

- 工具里最像"方法论"的部分不是 prompt，而是设置页：置信度阈值、多文档实体验证、本体质量验证都是可开关、可调档的。作者把"约束的合理性"从一句原则变成了几个旋钮。
- 该工具本身是"直给派 + 约束"的混合体，印证了五种流派边界模糊的判断。
