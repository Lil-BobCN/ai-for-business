# Codex

Codex 是 AI 协作开发工具。本页记录课程材料中的使用语境，不对 Codex 的具体版本、地区可用性或实际效果作独立确认。

## 课程中的工具定位

第 11 集作者将 Codex 列为零基础学习 FDE、降低应用开发门槛时可以使用的工具之一。

第 5 集作者把 Codex 与 Claude Code、`cursor`、DeepSeek Harness 并列为 AI 编程或学习工具，建议学习者先掌握 AI 编程基础，再进入需求拆解、技术架构选型、评估上线和项目开发。

第 5 集答疑中，作者还提到其团队使用 Codex 进行实际开发，并称国内用户可以使用 Codex。这些说法属于视频作者的口播主张，未提供版本、用户统计、团队项目记录或独立验证材料。

## 课程中的用途

第 2 集导学中，作者计划使用 Codex 将 CSV、PDF 等零散企业资料整理为 Ontology 实体及关系结构，预期产出包括实体结构和实体之间的关联关系。这是来源描述的教学用途，不代表其建模效果已经得到验证。

文稿没有说明生成结果如何审查、业务方是否确认、字段冲突如何处理，或如何通过问答效果发现建模错误。

## 来源观点

第 11 集作者认为，学习者可以借助 Codex、Claude Code、DeepSeek Harness 或其他 Agent 工具完成文档、方案和项目开发，从而把注意力放在业务理解、技术原理、架构选型和项目落地上。

作者还强调应当“驾驭 AI”，即根据需求指导 Agent 完成开发，而不是不加判断地接受生成结果。

## 可转化为 FDE 的能力要求

这些课程内容可以转化为以下 FDE 能力要求：

- 能把业务痛点转化为可执行需求；
- 能判断 Agent 生成的方案是否符合业务和技术约束；
- 能选择合适的 workflow、tool calling、RAG 或 Ontology 方案；
- 能通过测试、评测和运行日志验证交付结果；
- 能审查由 AI 生成的实体、属性、关系和数据处理代码。

## 边界与待核验项

AI 协作开发降低的是部分编码门槛，不会自动解决数据治理、权限、业务规则、评测、部署和运维问题。

来源没有提供 Codex 的版本、具体使用过程、生成代码样例或学习者效果数据，也没有提供课程学员的完成率、项目质量或就业跟踪数据。因此，不能据此证明使用 Codex 必然达到 FDE 岗位能力，也不能证明它能可靠地从企业资料中生成正确本体。

第 5 集没有说明 Codex 与课程自研本体平台、LangGraph、Semantica 或 RAG 之间的具体接口关系。相关工具职责和系统接入边界见 [[本体与 Agent 接入边界待核验]]。
