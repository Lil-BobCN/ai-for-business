# Wikidata

Wikidata 是一个开放协作的知识库（独立可核验的公开背景：它由 Wikimedia 基金会运营，为维基百科等项目提供结构化数据支持）。在该集视频中，它被作者引为"框架派"本体构建方法所依赖的开放知识库。

## 来源观点（作者口播，`unknown`）

作者称 Wikidata 是"全球最大的开放的知识库，里面有几亿个实体"。在框架派方法中，先定义好可以有什么类型、什么样的关系，再让 LLM 基于这个框架去提取实体，不能乱发明，从而减少幻觉、输出天然符合共识与合规的实体类型。

作者称，如果所在行业有标准规范（如医疗、法律、电力），框架派方式最合适，因为本身有标准 schema，可以基于该框架提取 Ontology。
