# 图遍历与 BFS 扩展

图遍历与 BFS 扩展是从一个或多个种子节点出发，按关系逐层访问相邻节点的检索方法。BFS 的通用含义是广度优先搜索；本集只把它作为视频作者描述的实现思路，未提供可执行代码或参数定义。

## 来源观点

作者说，系统先从自然语言输入中找到种子实体，经过去重、清洗和校验后，再沿本体图以 BFS 向外扩展，并根据参数返回一定数量的结果。

## 项目分析

种子实体决定搜索起点，扩展层数或返回条数决定上下文规模。这个方法适合补全订单、包裹、商品、物流等多跳关系，也可以作为向量召回之后的图扩展阶段。

## 边界

种子实体命中错误时，增加扩展深度通常会带来更多无关节点。图关系缺失、关系方向错误、循环结构和重复节点也会影响结果质量。BFS 只描述遍历顺序，不等同于相关性排序、规则推理或事实可信度判断。

## 待确认问题

- Semantica 是否确实使用 BFS，以及扩展深度和条数参数的正式名称。
- 图遍历是否有关系类型、权限和时间条件过滤。
- 多个种子实体如何合并，重复关系如何处理。
- 遍历结果如何与来源文件和答案引用绑定。
