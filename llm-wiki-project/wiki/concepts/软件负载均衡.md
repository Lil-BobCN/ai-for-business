# 软件负载均衡

软件负载均衡指在普通服务器上运行的负载均衡软件，通过安装软件即可实现负载均衡功能。本页记录 [[架构师阿Q]] 第 5 集口播中对这一类别及其中代表产品的描述。

## 定义

视频作者在该段口播中提出：软件负载均衡是指可以在普通服务器上运行的负载均衡软件，实现负载均衡功能。

## 来源观点（`unknown / 待外部核验`）

作者列举的常见软件及其定位：

- **Nginx**：七层负载均衡，支持 HTTP 协议。
- **HAProxy**：也是七层负载均衡软件，性能也很不错。
- **LVS**：纯四层负载均衡，运行在内核态，作者称其性能是软件负载均衡中最高的，因为工作在四层所以也更通用。

作者给出的优点：简单、部署维护简单、便宜（买个 Linux 服务器装上软件即可）；灵活（四层和七层负载均衡可以根据业务进行选择）；方便进行扩展和定制功能。

## 已核验事实

本页暂无工具直接验证的事实。产品层次归属与性能排名均为作者概括，本集对 Nginx、HAProxy 各仅一句定性描述。

## 项目分析

- 本集在软件方案内部给出的分工是「七层用 Nginx／HAProxy，四层用 LVS」，这一分工是 [[四层与七层负载均衡]] 概念页的主要来源依据。
- 作者把 LVS 的卖点归结为「纯四层 + 内核态」，即用放弃应用层解析换取转发性能。

## 反例与边界

- 「LVS 性能是软件负载均衡中最高的」是定性断言，本集无压测数据支撑。
- 本集未讨论 Nginx、HAProxy 与 LVS 组合使用时的分层职责，也未讨论各产品的健康检查与配置复杂度差异。
