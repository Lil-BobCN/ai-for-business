# 制品即说明书

制品即说明书是视频作者 catface996 在《Ontology：AI Coding 在本体中的建模和实战》中提出的一个观察：当制品（如缺陷）的字段定义足够完整时，指导录入的 skill 或 command 就变得多余。

## 定义

作者以缺陷（defect）为例：当缺陷的字段（内容、required、严重性、根因等）管理得非常明确时，它本身就是说明书，不需要再写一个"如何录入缺陷"的 command 或 skill 来指导。作者由此提出：能不能把语义、或者制品本身就做成规范本身。

## 来源观点（均归属 catface996，`unknown / 待外部核验`）

- 作者认为这是本体的一个比较好的地方。
- 该观察在很多知识管理场景里也成立：结构定义得越清楚，说明文档就越没有必要。

## 已核验事实

- 无。该观察为作者主张，未做独立核验。

## 项目分析

该概念是可迁移观察，与 [[concepts/强制力四层排序]] 呼应：结构定义越清楚，越靠近机器可判定层，越不依赖提示词或说明文档。

## 反例或边界

- 作者未论证字段定义"足够完整"的判定标准，也未说明字段频繁变化时说明书是否重新必要。
