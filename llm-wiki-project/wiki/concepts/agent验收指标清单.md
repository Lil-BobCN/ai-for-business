# Agent 验收指标清单

## 定义

Agent 验收指标清单，是视频作者提出的用考试式 evaluation 验收 Agent 的指标集合，用于判断 Agent 是否真正达成业务目标，而不是只看它嘴上说做完了。

## 来源观点

视频作者在该段口播中提出（`unknown / 待外部核验`），要用考试的方式进行验收，做好 Agent 的 evaluation，具体看：

- 业务结果对不对，而不是看它嘴上说做完了就认为它做完了；
- 越权率；
- 人工介入是不是按预期的步骤执行；
- 延迟；
- 成本；
- 换了模型还稳不稳；
- token 消耗率。

作者称这些都是做 AI 项目的验收指标，尤其是 Agent 的验收指标。他还提到「整理了一个项目评审清单」，但口播中没有读出清单内容，无法核对。

## 已核验事实

无。本页内容全部来自视频作者口播，尚无一手资料或独立核验支持。

## 项目分析

本清单与既有 [[concepts/业务验收指标口径]] 高度互补，可互相补全指标项：本集新增了越权率、换模型稳定性、token 消耗率等维度。可延展方向：把「证据点、规则、审批记录」的可审计三元组（见 [[concepts/agent可解释性不可信与可审计三元组]]）与这些指标一起纳入验收模板。

## 反例或边界

- 「接管率、失败样例」被当作升级依据，但高接管率既可能是 Agent 能力不足，也可能是上游数据口径问题的症状；作者未区分。
