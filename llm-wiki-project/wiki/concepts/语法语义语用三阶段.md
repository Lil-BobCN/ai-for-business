# 语法—语义—语用三阶段

## 定义

语法—语义—语用三阶段，是《标准语义知识库 第 1 部分：标准内容语义化表达通用要求》编制说明中提出的论证框架：将 ISO/IEC 的 SMART 标准数字化模型第 2、3、4 层分别对应语法、语义、语用三个阶段。

## 来源观点

编制说明的对应关系（来源作者提出，证据状态 unknown）：

- **第 2 层机器可读文档 → 语法阶段（结构化）**：将标准文档拆解为篇、章、节等内容，并转化为 XML 或 JSON 文件。
- **第 3 层机器可读内容 → 语义阶段（知识化）**：将标准内容通过语义化表达单元模型转化为具有语义关联关系的数据或知识，形成标准语义知识库。
- **第 4 层机器可解释内容 → 语用阶段（知识应用）**：将标准知识通过各种数字化技术或模型开展场景应用，如基于知识图谱推理、预测、问答等。

来源据此主张：语义化是打通语法到语用的关键环节，是实现标准数字化与现实场景融合的必经之路。

## 已核验事实

- 该三阶段对应关系在来源编制说明中明确出现。
- SMART 模型与 SAM 模型由 ISO 和 IEC 提出，来源将其描述为 5 个层次（第 0 层传统纸质层至第 4 层机器可解释内容）。

## 项目分析

该框架把 concepts/标准内容语义化 定位为语法与语用之间的中间环节，为 concepts/标准语义知识库 的存在必要性提供论证。它与 concepts/smart标准五阶段 共享同一 SMART 分层基础，但侧重强调第 2/3/4 层的阶段属性。

## 反例或边界

- 来源未给出“语法/语义/语用”三阶段划分的独立文献出处，属作者归纳。
- 第 0 层与第 1 层（传统纸质层、开放数据格式）未纳入三阶段对应。
