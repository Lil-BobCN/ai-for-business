# 把 Agent 当软件管理

「把 Agent 当软件管理」是「零点未来：AI+企业」第 10 集描述的治理方法：把 Agent 视为一个 LLM Application（完成任务的应用程序），纳入软件工程流程——放进 GitHub 仓库、每次修改提交 PR 由人审批、具备版本回滚与审计。

> 归属说明：本页为该视频作者的主张，属 `unknown / 待外部核验`。

## 定义

作者说，Agent 其实是一个 LLM Application，相当于一个软件工程，只是以前写逻辑代码，现在有 Prompt、一堆配置条件、工具、大模型评测和 Agent 记忆；这些东西都放进 GitHub 仓库，每次修改都必须提交 PR，由人来审批。

## 来源观点

- 审批人可能是 AI 开发团队；版本回滚和审计随之具备。
- 作者强调：非技术人员能造 Agent，但不等于谁都能轻易上线；治理是前置条件而非事后补丁。
- 治理链条：仓库、PR、人工审批、版本回滚、审计。

## 已核验事实

无。本集未提供独立一手资料。

- 隐含前提：企业本来就有软件工程纪律（仓库、PR、审计、回滚），而这恰恰是很多企业缺的。

## 反例或边界

- 本集未说明审批吞吐与例外处理机制。
