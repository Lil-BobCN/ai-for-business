# 语义化表达单元存储要求

语义化表达单元存储要求是 GB/T 46917.1-2026 征求意见稿第10章规定的、标准内容语义化表达单元在存储时的字段类型、存储方式、介质与安全、信息管理要求。

## 一、定义

存储要求规定标准内容语义化表达单元及其内容数据在数据库中的存储规范，包括字段类型、存储方式、存储介质与安全、存储信息管理四个方面。

## 二、来源观点（本文件正文第10章）

### 10.1 存储字段类型

```
a)字符串字段：用于存储定长字符串和变长字符串；
b)数值字段：用于存储整数和实数；
c)日期字段：用于存储日期类型数据；
d)时间字段：用于存储时间类型数据；
e)文本字段：用于存储文本中的句子和段落。
```

### 10.2 存储方式

```
a）标准内容语义化表达单元及其内容数据应按照上述表格顺序（见表3~表10）依次装入数据库；
b）将内容数据映射到标准内容语义化表达单元数据库；
c)同一数据库可存储多种格式的内容数据,不同记录(行)的内容数据的格式可不同；
d)同一条记录可存储一个或多个内容数据,同一条记录(行)中多个内容数据的格式可不同。
```

### 10.3 存储介质与安全

标准内容语义化表达单元数据库应存储在机械硬盘和固态硬盘等存储介质上，应在不同的存储介质之间转移。数据库应保存在安全的存储系统中和存储介质上，防止被非授权改动数据库存储位置的设置，并保障数据不被非授权修改、访问、删除、复制和破坏，对授权修改、访问、删除和复制要做审计跟踪。涉密数据在线存储应加密，涉密数据导出和备份应采取数字签名等安全措施。

### 10.4 存储信息管理

```
a）存储数据的基本信息（如存储时间、存储人员等），应能溯源数据修改、删除等操作；
b）存储过程中出现的问题或错误的信息；
c）存储数据跨系统、跨版本的存储数据逻辑应一致，无冲突；
d）针对关键数据（如指标数据）应进行人工复核。
```

## 三、已核验事实

- 第10.1–10.4条的条款文本为征求意见稿正文直接还原（`partial`，未校对）。

## 四、项目分析

- 第10章存储要求与 [[entities/gb-t-46917-2-2026-数据接口要求]] 形成“存储—接口”分工：本文件规定数据如何存储，第2部分规定数据如何通过接口访问。
- 10.2 a）要求按表3–表10顺序装入数据库，与 [[concepts/表达顺序性与语义完整性]] 的表达顺序性呼应。
- 10.4 d）要求关键数据人工复核，体现人机协同机制。

## 五、反例或边界

- 第10章未明确存储要求与第2部分数据接口要求的边界划分。
- 10.2 未明确“多种格式”的具体格式范围。
