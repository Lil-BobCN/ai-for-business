# Agent 可解释性不可信与可审计三元组

## 定义

Agent 可解释性不可信与可审计三元组，是视频作者提出的验收原则：不要相信 Agent 讲出来的解释，而要看证据、规则、审批记录；把「证据点 + 规则 + 审批记录」当成一个可审计三元组，要求每一次 Agent 动作都能同时回溯到这三样。

## 来源观点

视频作者在该段口播中提出（`unknown / 待外部核验`）：

- 不要信 Agent 的可解释性。不要信它讲一堆大道理——看起来解释得头头是道，但不代表它真的是这么想的，也不代表它真的是这样的执行路径。
- 具体还是要看证据、看规则、看审批记录。
- 作者称「有研究就点破过：模型的解释越漂亮，可能根本没有说实话」，但未给出处。
- 报销单案例的落点：数字、规则、审批记录这些才是关键，可信度来源于全部的证据点和数据，而不是它随口推理就给你一个结论。

## 已核验事实

无。本页内容全部来自视频作者口播，尚无一手资料或独立核验支持。「模型解释不可信」的研究出处待核验。

## 项目分析

作者把「看解释」和「看证据」分开，等于把审计对象从模型的措辞换成了系统留下的记录：规则怎么写的、谁批的、数据从哪来。解释可以生成，记录必须被留下。可延展方向：把「证据点、规则、审批记录」当成一个可审计三元组，要求每一次 Agent 动作都能同时回溯到这三样。

## 反例或边界

- 如果只认结果和记录，那模型给出的理由在现场还有什么用——是给人提供线索，还是给人制造安慰？作者未展开。
