# 数据接口建设与应用原则

数据接口建设与应用原则是 GB/T 46917.2-2026《标准语义知识库 第2部分：数据接口要求》编制说明列出的六项主要内容中的第 1 项，指标准语义知识库数据接口在建设与应用中应遵循的四项原则：**通用性、实用性、安全性与可用性**。

## 来源观点（起草组自述）

编制说明对该原则的表述为：

> 遵循通用性、实用性、安全性与可用性原则，要求接口兼容多层级标准及主流系统，设计以业务需求为导向，采用加密、认证机制保障数据安全，支持高负载与异常条件下的稳定运行。

四项原则的对应要求可拆解为：

| 原则 | 编制说明中的对应要求 |
| --- | --- |
| 通用性 | 接口兼容多层级标准及主流系统 |
| 实用性 | 设计以业务需求为导向 |
| 安全性 | 采用加密、认证机制保障数据安全 |
| 可用性 | 支持高负载与异常条件下的稳定运行 |
