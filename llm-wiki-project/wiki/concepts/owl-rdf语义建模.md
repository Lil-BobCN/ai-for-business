# OWL/RDF 语义建模

OWL（Web Ontology Language）与 RDF（Resource Description Framework）是 W3C 体系下用于形式化表示知识、支持机器可读与语义互操作的语义建模技术。OWL 用于定义本体中的类、属性、个体及其逻辑约束，RDF 用于以三元组形式表达资源之间的关系。

> 独立可核验背景：OWL 与 RDF 均为 W3C 发布的公开技术规范，其定义与用途可在 W3C 官方文档中独立查证。本页对该技术本身的描述属于此类公开背景，不来自本来源。

## 来源观点

在 GB/T 48000.3-2026《标准数字化 第3部分：本体建模要求》编制说明中，起草组主张：

- 本标准**基于 OWL/RDF 语义建模技术**，构建结构化本体模型，实现标准知识的形式化表示，支持机器可读与语义互操作。
- 第 5 章“实体类型和属性的定义方式基于相关元数据定义及网络本体语言等”。
- 起草过程第二次全体会议后“增加 OWL、实例化示例附录”。

以上均为起草组自述，证据状态 `unknown`，尚无独立核验。

## 项目分析

OWL/RDF 在本来源中承担的是**技术先进性论证依据**的角色，而非标准正文条款本身。编制说明未给出 OWL/RDF 的具体版本、Profile（如 OWL 2 EL/QL/RL）或与附录 A 属性表格的映射细节，因此无法从本文件判断标准正文实际采用了哪一层语义表达强度。

## 反例或边界

- 编制说明称“基于 OWL/RDF”，但未说明是否强制要求实现方使用 OWL 推理机，也未说明与 SHACL 等约束语言的取舍。
- 本文件未提供任何形式化验证或一致性检查结果。
