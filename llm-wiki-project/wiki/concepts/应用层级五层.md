# 应用层级五层

应用层级五层是 GB/T 48000.2-2026（征求意见稿）参考架构模型中**应用层级维度**的层级结构，描述标准数字化相关应用与服务所涉及的范围与对象，自下而上划分为**标准信息层、信息交互层、相关信息层、场景服务层、业务生态层**五个层级。该维度对应 GB/T 48000.1 提出的标准应用数字化方面。

## 定义与来源观点

来源（第 8 章）称各层级宜按照 GB/T XXXXX.1—XXXX 第 9 章开展相关活动。各层级要点如下：

- **标准信息层**：为了将标准内容进行数字化应用，由标准文本、语义、功能信息单元及组成 SIM 的基础的数据/信息层级。一般包含：
  - **文本层**：由大量结构化的文本信息单元组成，存储和表达结构化的标准本体信息，实现对标准中的文本段落、表格、图片以及公式等信息的结构化储存；
  - **语义层**：将文本层转化为具有语义关联关系且便于计算机理解和处理的数据或知识，由语义信息单元组成，存储和表达标准要素的技术特性；
  - **功能层（基于标准自身内容的功能层）**：标准文本层信息和语义层信息面向不同标准化场景的组合和多样化表达，以功能信息单元集合的形式，提供可执行的标准服务能力，如标准检索、标准指标对比、标准关联引用等。
- **信息交互层**：为了实现标准信息层与其他相关数据/信息的数据传输与交换，由二者接口组成的层级。一般包含：元数据集合、索引信息（索引信息模型元数据的定义宜按照 GB/T 22373 要求，包括标准号、发布日期、发布机构、标准状态等）、标准化对象信息、功能信息、数据接口（通过开放的同步或异步 API 实现标准信息层与相关信息层之间的结构化数据交换）。
- **相关信息层**：由标准相关的其他数据/信息组成的层级，这些数据/信息能够与标准配合，形成满足场景所需的特定功能。一般包括但不限于：标准相关属性信息、变更信息；标准所属标准体系、体系中的定位、与其他标准的关系；相关规范性文件；相关专利及必要专利；相关技术文件；相关生产数据和测试数据；相关操作说明；相关业务场景信息。
- **场景服务层**：为了实现单个独立场景的使用需求，由基于标准及相关数据/信息形成的特定功能与服务组成的层级，包括信息服务、软件工具服务、系统集成服务等多种模式。一般包括：用户需求、业务场景（如合规分析、模型校验等独立场景）、实现方案、交付形式、实施过程、实施效果。
- **业务生态层**：为了满足组织过程和业务过程的需求，为实现多个标准数字化场景，由若干标准数字化系统平台及相关活动组成的层级。一般包含：软硬件资源、组织条件、配套政策及制度、人才培养及发展激励、技术投入和资金保障、业务流程动态管理和优化、业务流程无缝衔接和协同、知识共享和流通、基于多场景的标准数字化业务生态。注：业务生态层通常不涉及具体系统与特定解决方案，系统功能通常包含于“场景服务层”。

## 已核验事实

- 五层级名称与顺序出自 GB/T 48000.2-2026 征求意见稿第 8 章，属**草案自述**（`partial`）。
- 标准信息层三层结构（文本层/语义层/功能层）为来源原文。
