# 自愈成功率与报错引导修复

自愈成功率与报错引导修复是视频作者 catface996 在《Ontology：AI Coding 在本体中的建模和实战》中描述的一对机制与指标：agent 拿到报错后自我修复的比例，以及把失败信息设计成下一步输入的做法。

## 定义

- **报错引导修复**：当 agent 操作本体违反规则（如保存五段 URL 被拒）时，系统返回引导性报错（如"Jenkins 路径必须为 `{服务}/{资源}/{操作}`"），引导 agent 修复。
- **自愈成功率**：agent 拿到报错后自我修复的比例，是作者列出的度量指标之一。

## 来源观点（均归属 catface996，`unknown / 待外部核验`）

- 演示中五段 URL 保存被拒，返回 `Error type pattern` 报错；作者称 agent 拿到这条消息后"大概率一定能够把自己自愈掉"。
- 作者强调：违反本体规则时一定要把报错信息设置清楚，失败后报错返回给 agent 并引导其修复。
- 自愈成功率与"报错引导修复"直接相关，是 loop 机制能否自愈的前提。

## 已核验事实

- 演示中"五段 URL 被拒并返回引导性报错"是可观察的系统行为，属演示事实（但仍为作者自述，非独立核验）。

## 项目分析

该概念与 [[concepts/成功率连乘与单步确定性]] 直接相关：把失败信息设计成下一步的输入，是 loop 能不能自愈的前提。与既有 [[concepts/agent-反馈闭环与自我进化]] 呼应。

## 反例或边界
