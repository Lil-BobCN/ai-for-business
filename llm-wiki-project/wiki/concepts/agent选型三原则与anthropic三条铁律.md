# Agent 选型三原则与 Anthropic 三条铁律

本页记录「零点未来」第 8 集视频作者给出的 Agent 模式选型原则，以及作者转述的 Anthropic 三条铁律。两者构成本集的收束性结论。

## 选型三原则（来源观点，`unknown / 待外部核验`）

1. **从简单开始**：能确定的部分就用 Prompt Chaining。
2. **逐步增加复杂度**：先把一个简单的流程跑通，然后需要动态决策、或者说领域要分离开来，不同领域用不同的 Agent，这样逐步去增加复杂度。
3. **组合**：用不同的组合去完成整个任务，比如一个确定的 Prompt Chaining 里面，某一个步骤就是让 Agent 去动态调 API，常常比整体进行升级更划算。

## Anthropic 三条铁律（作者转述，`unknown / 待外部核验`）

1. **保持简单**——最成功的系统没有用复杂的框架；
2. **透明可解释**——能解释、能展示 Agent 的规划步骤；
3. **精心打磨 Agent 和工具的接口**，这个值得更多的投入。

## 项目分析

- 三原则与三条铁律在立场上一致：先简单、按需增加复杂度、用组合而非整体替换来演进。
- 作者最实用的一句是：在一个确定的提示链里，只把某一步换成 Agent 动态调 API，常常比整体升级更划算。这让架构决策变成了一个可以逐步推进的步骤题。
- 可延展方向：把现有流程图直接当作升级地图，逐步替换，每一步都留一个可以回退的开关。

## 反例或边界

- 作者一方面强调「从简单开始、最成功实现不用复杂框架」，另一方面又用大量篇幅铺开七种模式与多 Agent 架构，读者可能误读为「模式越多越好」；作者用「组合而非整体替换」部分化解，但张力仍在。
- 三条铁律的原文归属与措辞未给出，属二手转述。
