# 本体构建选型双轴

## 定义

"本体构建选型双轴"是视频作者零点未来在该集口播中提出的选型判断框架：用**工程复杂度**与**幻觉风险**两个维度综合选择本体构建流派，其分界线是"玩具"与"生产系统"。

## 来源观点（作者口播，`unknown`）

作者给出的简单判断框架：

- **快速试试 / PoC 验证方向** → 直给派（LLM + prompt 直接提取 Ontology）；
- **探索全新领域、不知道里面有什么** → 聚类派（让数据告诉你答案）；
- **已有行业标准和现成知识体系** → 框架派（用 Wikidata 或行业标准约束，让 LLM 输出合规 Ontology，少走弯路）；
- **上生产系统、不能出错** → 拆解派 + 双重验证机制（工程量较大，但作者称结果最好）。

作者称这就是"玩具"和"生产系统"之间的分界线。

## 项目分析

- 两个维度对应两种不同的代价：工程复杂度对应人力代价，幻觉风险对应错误代价。直给派省下的是人力，付出的是错误；拆解派相反。
- 可追问：如果错误可以被人拦住（如人工审核），"玩具派"能不能也进生产？
- 可延展方向：给每个流派补一列"错误在什么时候被发现"，往往比补一列"幻觉概率"更能决定它能不能上生产。

## 反例与边界

- 作者把选型压成两个维度，但幻觉不是唯一成本；错误被发现的时间点同样关键。
- 五种流派边界模糊，实际方案常为混合体（如 OntoPrompt 即直给派 + 约束）。
