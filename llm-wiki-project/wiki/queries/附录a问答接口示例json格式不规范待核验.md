# 附录A问答接口示例JSON格式不规范待核验

## 问题

GB/T 46917.2-2026 征求意见稿附录 A（资料性）问答接口示例的 JSON 格式不规范，不符合标准 JSON 语法。

## 当前已知

- 请求数据末尾有多余逗号：`"elementType":"terminology",}`。
- 响应数据中中文引号与英文引号混用（`” ”`），如 `{"terminology":主体变压器, ” ”`。
- 响应数据中 `srcStandardNum`、`srcStandardName`、`timeStamp` 的值被中文引号包裹。

## 缺口

- 这些格式问题是征求意见稿原文问题，还是文本还原过程中的引号转换错误，需回官方 PDF 核对。
- 若为原文问题，正式发布版是否已修正。
