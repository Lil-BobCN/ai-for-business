# “国内 RAM 研究几乎为零”主张待核验

## 问题本身

GB/T 48000.2-2026 编制说明称，我国面向标准化的 RAM 构建和应用研究“几乎为零”，并称本标准“国内首次提出了面向标准数字化的参考架构模型”“填补了标准数字化活动管理缺乏工具与方法指导的空白”。这些属起草组自述性判断，需外部核验。

## 当前已知

- 起草组在同一文件中列出国内与 RAM 相关国家标准共计 40 余项，包括 GB/T 40647-2021《智能制造系统架构》、GB/T 40287-2021《电力物联网信息通信总体架构》、GB/T 40020-2021《信息物理系统参考架构》、GB/T 40778.1-2021《物联网 面向 Web 开放服务的系统实现 第1部分：参考架构》、GB/T 23004-2020《信息化和工业化融合生态系统参考架构》、GB/T 35279-2017《信息安全技术 云计算安全参考架构》等（来源：本编制说明，`partial`）。
- 起草组以“上述标准均聚焦各垂直行业领域，未涉及面向数字化的标准化领域”作区分。

## 冲突来源

- 起草组主张（`unknown`）：“几乎为零”“国内首次”“填补空白”。
- 同一文件列出的 40 余项国内 RAM 相关标准：说明国内 RAM 研究并非空白，只是领域不同。
- 张力点在于“面向数字化的标准化领域”这一限定边界是否足以支撑“几乎为零”的表述。
