# 标准数字化平台比 ISO OSD、IEC 更系统化主张待核验

## 问题本身

本来源编制说明第四节称本标准所提出的标准数字化平台系统架构所涉及的标准数字化内容和过程比 ISO 的 OSD 平台及其方法、比 IEC 有关数字化平台的方法"要多，并且更系统化"，属作者主张，需外部核验。

## 当前已知

编制说明原文（逐字）：

> 但本标准所提出标准数字化平台系统架构所涉及的标准数字化内容和过程比 ISO 的 OSD 平台及其方法要多，并且更系统化。

> 但本标准所提出数字化平台系统架构所涉及的标准数字化内容和过程比 ISO 的 IEC 有关数字化平台的方法要多，并且更系统化。

编制说明同时列举了 ISO 与 IEC 的方法：

- ISO：STS（标准标签集）内容结构化；OSD 平台基于 XML 标准标签组件模式编写文件，OSD 2.0 采用 STS 模式。
- IEC：标准化工作协作平台、术语和词汇数据库、电气图形符号数字库；标准在线编写工具、标准映射工具；统一管理壳/接口；SIU（标准信息单元）和 SIM（标准信息模型）构成标准资源库。

## 冲突来源

- "更多、更系统化"为定性自评，未给出量化对比指标或对比方法。
- 与既有 queries/iso-iec-osd平台2025年1月全面推行待核验 相关。

## 缺口

- 缺少 ISO OSD 平台与 IEC 方法的完整功能清单，无法逐项对比。
- 缺少"更系统化"的判定标准。
