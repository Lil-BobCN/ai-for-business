# SMART 五层次与 SAM 模型关系及既有页面口径一致性待核验

## 问题本身

GB/T 46917.1-2026 编制说明在背景论证中同时援引 **SMART Standard 概念模型**与**标准架构模型（Standardization Architecture Model，SAM）**，并称二者"将标准数字化过程划分为 5 个层次"（第 0—4 层）。但编制说明**未说明 SMART 与 SAM 二者之间的关系**，也未说明 5 个层次究竟由哪一个模型提出。

## 当前已知（来自本来源，起草组自述，`unknown`）

- 编制说明表述："国际标准化组织(ISO)和国际电工委员会(IEC)提出 SMART Standard（Machine Applicable, Readable and Transferable）标准的概念模型，以及标准架构模型（Standardization Architecture Model，SAM），将标准数字化过程划分为 5 个层次"
- 5 个层次：第 0 层传统纸质层、第 1 层开放数据格式（如 PDF）、第 2 层机器可读文档、第 3 层机器可读内容、第 4 层机器可解释内容（智能标准）
- 编制说明将第 2/3/4 层分别映射为语法/语义/语用阶段

## 冲突与缺口

1. **SMART 与 SAM 的关系不明**：编制说明将二者并列提出，但未区分各自职责与层次归属。既有 [[sam模型]] 页与 [[smart标准概念模型]] 页的口径是否与本文件一致，需核对。
2. **层次数口径**：本文件称"划分为 5 个层次"（第 0—4 层）。既有 [[smart标准概念模型]] 页记录的层次数与维度口径是否一致，需核对。
3. **维度口径**：既有 [[sam模型三维度与本文件三维度内涵一致性待核验]] 涉及 SAM 三维度问题，本文件未提及 SAM 的维度划分，二者关系待厘清。
4. **语法/语义/语用映射的准确性**：本文件将第 2/3/4 层映射为语法/语义/语用阶段，该映射是否为 ISO/IEC 原始模型的表述，还是起草组的解读，需外部核验。
