# 四层架构是分工还是施工顺序待核验

## 问题本身

视频作者在"零点未来：AI+企业"第 9 集中给出四层全景架构（定义层 / 表示层 / 工程层 / 应用层），并把定义层称为"基础"。这四层是各管一段的分工，还是一道严格的先后施工顺序？

## 当前已知（作者口播，`unknown / 待核验`）

作者原述四层：

| 层 | 内容 |
|---|---|
| 定义层 | ontology，定义概念与语义关系，是基础 |
| 表示层（表征层） | 知识图谱、上下文图谱、代码数据 |
| 工程层 | graph engineering，给 Agent 的工程运作 |
| 应用层 | 给 Agent 提供的运行环境与运行工具 |

## 冲突来源

- 定义层被放在最底下、被称作"基础"，隐含"先后工序"。
- 但另外三层并不会等它做完才存在——企业里通常已经有数据、有代码、也有在跑的流程，隐含"各管一段"。
- 本来源作者未明确说明四层是分工还是顺序。

## 缺口

- 缺少作者对四层之间依赖关系的明确表述。
- 缺少定义层未覆盖某域时上层如何表现的案例。
