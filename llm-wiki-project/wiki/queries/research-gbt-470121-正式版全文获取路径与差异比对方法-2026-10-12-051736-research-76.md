# GB/T 47012.1 正式版全文获取路径与差异比对方法

本页汇总现有检索证据，梳理 GB/T 47012.1-2026《标准数字化平台 第1部分：系统架构》正式版全文的可获取渠道，并给出与已归档的 2025-04 征求意见稿进行条款级差异比对的操作方法。需要说明的是：现有来源仅覆盖元数据、平台收录说明与体系定位，尚未取得正式版正文，因此当前进度处于"路径确认 + 方法准备"阶段，条款级比对本身仍未启动，与 [[正式发布版全文未获取与条款级比对待启动]] 的记录一致。

## 一、标准身份与状态

- **标准编号**：GB/T 47012.1-2026（GB/T 前缀表明其为推荐性国家标准）。
- **中文名称**：标准数字化平台 第1部分：系统架构；**英文名称**：Platform on standard digitalization—Part 1: System architecture [1]。
- **发布与实施**：发布日期 2026-01-28，实施日期 2026-08-01，状态为"现行"（部分平台仍在实施日前将其标注为"即将实施"）[2][3]。
- **体系定位**：在"标准数字化"专题检索中，本标准被归入标准体系 **D.1 平台工具** 分支，并被列为第 16 项条目 [2]。此定位可与 [[5-标准数字化--11-01-标准族总览与关系--itsv1r]] 记录的标准族关系对照。
- **系列归属**：属于 [[gb-t-47012-标准数字化平台系列标准]]，条目页见 [[gb-t-47012-1-2026-系统架构]]；与 [[gb-t-48000-标准数字化系列标准]]、gb-t-46917-标准语义知识库系列标准 的体系关系仍待核验，见 47012与48000系列标准关系待核验 与 gb-t-47012-1标准编号占位符与发布状态待核验。
- **平台条目写法差异**：地方平台将中文名称写作"标准数字化平台第1部分:系统架构"（无空格、半角冒号），与官方公开系统的"标准数字化平台 第1部分：系统架构"不一致 [1][3]；此类格式差异属编辑性差异，但会影响按键值检索命中的可靠性。

## 三、差异比对方法

### 3.1 证据准备与版本台账

- **基准文本**：wiki 已归档的征求意见稿全文，见 5-标准数字化--7-征求意见稿全文--32-23-gb-t-470121-2026-系统架构-征求意见稿全文--1chhxw5。
- **辅助文本**：征求意见稿及编制说明，见 [[5-标准数字化--4-标准原件--28-6-标准数字化平台-第1部分系统架构征求意见稿及编制说明--1cxm1mk]]；官方条目档案，见 [[5-标准数字化--4-标准条目--36-14-gb-t-470121-2026-标准数字化平台-第1部分系统架构--1s9cgy8]]。
- **对照文本**：待获取的正式版全文（见第二节路径）。
- **台账字段**：版本标识（征求意见稿/报批稿/正式版）、来源平台、获取方式、获取日期、文件名与哈希、页数。

### 3.2 四层比对

1. **结构层**：对齐章、条、款、项编号以及表号、图号、附录编号，输出"新增 / 删除 / 移动 / 合并 / 拆分"清单。标准正文中的章节号引用（如"见 6.2.1 表 1"一类写法）应作为重点核查对象。
2. **内容层**：逐条比对本语与定义、规范性引用文件、技术指标与参数、图表数据、示例与资料性附录。
3. **规范层**：核对助动词等级（应 / 宜 / 可 / 能）是否变化、规范性引用是否注日期、条款类型（要求 / 推荐 / 允许）是否变动——这类改动即使字数极少也可能构成实质性差异。
4. **元数据层**：编号占位符是否替换为正式编号、前言中"已发布部分"表述、起草单位与起草人名单、发布 / 实施日期、参考文献。

### 3.3 差异记录字段（建议模板）

差异编号 | 位置（章条 / 图表号）| 征求意见稿表述 | 正式版表述 | 差异类型（结构性 / 技术性 / 规范性 / 编辑性）| 是否实质性 | 影响范围 | 处理动作（更新 wiki 条目 / 新建 query）| 证据来源与访问日期

### 3.4 定向核对锚点

征求意见稿阶段已累积若干待核验项，可直接作为比对时的重点核查清单，逐项判断"正式版是否修正"：

- 编制说明7-4章节号重复待核验、[[编制说明第7章第8章节号引用错乱待核验]]——章节号引用体系是否在正式版中理顺；
- 图10实施架构功能模型内容错误待核验——图 10 及实施架构相关功能模型内容是否修正；
- 美嘉林公司名称不一致待核验、[[47012-1起草单位署名两组口径差异待核验]]——起草单位署名口径是否统一；
- [[标准数字化平台前言已发布部分表述待核验]]——前言表述是否更新；
- [[标准起草者术语来源gb-t-20002-3错配待核验]]——术语来源标注是否更正；
- [[标准数字化平台比iso-osd-iec更系统化主张待核验]]、iso-iec-osd平台2025年1月全面推行待核验——对外部标准与平台的比较性主张是否有据可查；
- 标准数字化平台试验验证独立性待核验——试验验证主体的独立性说明是否变化。

上述条目中的技术内容页也可作为理解正式版架构的参照，例如 [[标准数字化平台四层系统架构]]、标准数字化业务管理六化链、标准库知识库数据库三库集成、标准标签集-sts、标准主结构与条款主模型（含 smart标准五阶段）；若正式版结构发生变化，这些概念页需同步复核。

### 3.5 横向一致性核验

本系列标准同年份密集发布，应做跨标准的术语与引用一致性检查，重点对象包括 [[gb-t-48000-2-2026-参考架构模型]]、[[gb-t-48000-3-2026-本体建模要求]]、[[gb-t-48000-4-2026-协同制定要求]]、gb-t-46917-1-2026-标准内容语义化表达通用要求、[[gb-t-46917-2-2026-数据接口要求]]、[[gb-t-46917-3-2026-语义集成技术要求]]。可复用的比对框架有 gb-t-47012与iso-iec-osd平台比较 与 smart五阶段与能力特征五等级比较。

## 四、矛盾、张力与空白

1. **"可检索"与"可获取"的落差**：来源 [1] 只覆盖条目字段，来源 [4] 的收录与下载权限说明以强制性标准为口径，未明确推荐性国标（GB/T）的公开范围，需以实测结果为准。
2. **平台口径冲突**：来源 [3] 将本标准标注为"无文本、购买"，与官方公开系统及行业专题平台的收录状态形成张力。可能原因是地方镜像授权范围有限或数据同步滞后，而非标准本身不可得；在取得 A1 实测结果前，不宜采信任何单一平台的可得性判断。
3. **时间线影响**：发布日期 2026-01-28、实施日期 2026-08-01 [2]，公开系统上线通常滞后于发布公告，部分平台在实施日前仍显示"即将实施" [2]，因此检索结果需附访问日期。
4. **差异内容完全未知**：未见任何来源给出正式版正文，故与征求意见稿的差异性质（编辑性还是实质性）无法预判，见 [[gb-t-47012-1正式版与2025-04征求意见稿差异待核验]]。
5. **编号与系列关系悬置**：正式编号与征求意见稿占位符的对应、系列部分数量口径、与 GB/T 48000 / 46917 体系的归属关系均待核验，见 gb-t-47012-1标准编号占位符与发布状态待核验、gb-t-47012系列部分数量待核验、[[标准数字化平台第1部分标准编号与gb-t-47012-1关系待核验]]。

## 六、小结

路径层面，国家标准全文公开系统是首选且成本最低的获取通道，但其对推荐性国标的开放范围、以及本标准是否已上线，仍属未验证项；地方与商业平台只能作为元数据补充。方法层面，比对应以"结构 → 内容 → 规范 → 元数据"四层推进，以征求意见稿阶段遗留的待核验项为定向核查清单，并按统一字段记录差异，最终将结论回写到 [[gb-t-47012-1-2026-系统架构]] 及相应 query 页，形成可追溯的版本演进记录。
