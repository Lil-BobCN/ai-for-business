# 标准生命周期九阶段与既有四阶段概念关系待核验

## 问题

GB/T 47012.1-2026 征求意见稿第 3 章将"标准生命周期"定义为九阶段（预备、立项、起草、征求意见、审查、批准发布、出版、复审、废止），而既有 Wiki 页面 [[concepts/生命周期四阶段]] 记录的是四阶段划分。二者是否描述同一对象、是否需区分，尚待核验。

## 当前已知

- 本来源九阶段：预备、立项、起草、征求意见、审查、批准发布、出版、复审、废止。
- 既有 [[concepts/生命周期四阶段]]：四阶段划分（来源为 GB/T 48000.2-2026 参考架构模型相关来源）。
- 本来源第 7.4.2 节列举的阶段（立项、起草、征求意见、审查、批准发布、交付、应用反馈、复审）与第 3 章术语定义的九阶段在名称上不完全一致。

## 冲突来源

- 本来源正文（草案，`partial`）。
- 既有 [[concepts/生命周期四阶段]] 页面。

## 缺口

- 无法确认两套阶段划分是否针对同一标准化对象。
- 无法确认九阶段与四阶段的映射关系。
