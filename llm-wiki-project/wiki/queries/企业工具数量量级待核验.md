## 当前已知

- 草稿原文即写作「上千个三万个」，数字本身待确认。
- 作者举例：ERP 100 个接口、采购系统 200 个 action，再加 CRM、财务知识库、MCP server 等。
- 该数字用于论证 tool search 的必要性。

## 冲突来源

无直接冲突，但数字不可靠，不能作为事实使用。

## 缺口

- 缺少统计口径（是接口数、action 数还是工具定义数）。
- 缺少样本企业与统计来源。
