# 五层架构官方命名与划分待核验

## 问题本身

视频作者零点未来在「AI+企业」第 5 集中把 Agent 与 Ontology 的交互拆成 Context、Query、Logic、Action、Governance 五层，并称 Context Layer 的官方名为 Retrieval Context。这些命名与划分是否为 Palantir 官方口径？「Governance 贯穿前四层、是 Palantir 与普通 Agent 框架最核心差异」这一判断是否有官方依据？

## 当前已知

- 作者称第一层 Context Layer 官方叫 Retrieval Context。
- 作者称 Governance Layer 不是单独一层，而是贯穿前四层的约束机制。
- 作者称这是「Palantir 跟普通的 Agent 框架最核心的一些差异」。
- 以上均为作者口播，本地 ASR 为 `partial`，无一手文档佐证。
