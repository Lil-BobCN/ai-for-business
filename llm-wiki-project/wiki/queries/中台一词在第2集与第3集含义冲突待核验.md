# 「中台」一词在第 2 集与第 3 集含义冲突待核验

## 一、问题本身

「架构师阿Q」《架构和原理》合集中，第 2 集与第 3 集共用「中台」这个词，但含义不同。系列索引页将其列为「术语待确认」项，并建议区分而非统一纠正。

## 二、当前已知

- 第 2 集：指「六大基础服务平台」，是业务中台／数据中台的雏形，讲的是把通用能力下沉给业务线复用（**能力复用**）。
- 第 3 集：指「数据中台」，是把数据加工成标准资产并封装成 API，讲的是数据资产化与服务化（**数据复用**）。
- 系列索引页明确标记：两集连读时建议区分，一个是能力复用，一个是数据复用。

## 三、冲突来源

- 来源一：第 2 集（`BV1GN796nEJ9`）第六阶段，中台 = 六大基础服务平台。
- 来源二：第 3 集（`BV12qKq6PETb`）收尾，中台 = 数据资产化与服务化。
- 双方均为视频作者观点，`unknown / 待外部核验`。

## 四、缺口

- 作者是否在同一语境下有意区分这两个含义，尚不明确。
