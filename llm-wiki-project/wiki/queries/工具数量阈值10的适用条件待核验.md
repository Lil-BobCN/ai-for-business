# 工具数量阈值 10 的适用条件待核验

## 问题本身

「零点未来」第 8 集视频作者称「工具超过 10 个，而且这些工具可能还非常相似，那模型就会开始选错工具」。该经验阈值的适用条件、与模型版本和工具描述质量的相关性需核验。

## 当前已知

- 作者给出的量级：超过 10 个工具、且彼此相似，模型开始选错工具。
- 作者给出的对策：清晰命名、说明什么情况下可以用什么工具、给它一个范围。
- 作者把该问题归因于接口设计，而非单纯的模型能力。

## 冲突来源

- 无直接冲突来源，但该阈值属经验性说法，无一手数据支撑。

## 缺口

- 该阈值与模型版本、工具描述质量的相关性数据。
- 是否存在公开的工具数量与选择准确率的实验或基准。

- LLM agent tool selection accuracy number of tools benchmark
- LLM function calling too many tools similar descriptions error rate
- agent tool interface design naming description best practices
