# SAM 模型三维度与本文件三维度内涵一致性待核验

## 问题本身

GB/T 48000.2-2026（征求意见稿）引言称：IEC/SMB/SG12 在《SMB/7326/R》报告中提出的 SAM 模型（Standard Architecture Model）包括标准内容的生命周期、能力等级、层级三个维度，与 GB/T 48000.1 提出的过程数字化、内容数字化、应用数字化三个方面“内涵一致”。该主张是否成立？

## 当前已知

- 来源（引言）称 SAM 模型三维度为：生命周期、能力等级、层级。
- 来源（第 5 章）称本文件三维度为：能力特征、生命周期、应用层级。
- 来源未逐项对照 SAM 模型三维度与本文件三维度的确切定义。
- 参考文献 [6] 列出：IEC SMB/7326/R Report of SG 12 following its online meetings held on 2021-01-25 and 2021-05-06。

## 冲突来源

- 来源仅作“内涵一致”的概括性陈述，未提供 SAM 模型各维度的确切定义，无法直接验证。

## 缺口

- 缺少 IEC SMB/7326/R 原文或 SAM 模型的权威定义。
- 缺少 SAM 模型三维度与本文件三维度的逐项对照。

## 建议搜索式

- IEC SMB/7326/R SAM model Standard Architecture Model dimensions
- IEC SG12 smart standards architecture model lifecycle capability level
- IEC Smart Standards SAM model three dimensions definition
