# 端到端链路数字不自洽待核验

## 问题本身

视频作者零点未来在「AI+企业」第 5 集的端到端链路示例中，数字前后不一致：Query Layer 过滤后得到 32 个结果，Logic Layer 却说「23 个里面有 5 个有风险」。此外还有「四项列举 vs 三层叠加」「三十年 vs 三年」等不一致。这些是 ASR 误识、作者口误，还是演示流程本身不闭合？

## 当前已知

- 端到端链路：Top 10 注入 → 过滤华南仓加延误条件得 32 个 → 沿 Link 追溯 Order/Customer → 调用函数算风险（23 个中 5 个有风险）→ LLM 生成回答 → 用户确认 → 分派承运商、创建异常 case、更新 Ontology、留审计日志。
- 防幻觉机制列举四项（Context、Object Type、权限、函数），叙述中另有「三层叠加」说法。
- 「这个承运商过去三十年的表现」从上下文看疑为「三年」。

## 冲突来源

同一视频内部前后数字不一致，无法判断哪一侧为原音。

## 缺口

- 原音中 32 与 23 分别是什么。
- 防幻觉机制到底是几层。
- 「三十年」是否为「三年」。
