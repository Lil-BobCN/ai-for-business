# 问题分类标签

相关技能使用五种固定的问题状态。下表说明这些状态在本仓库中对应什么标签，以及各自代表什么。

| 技能中的状态 | 本仓库使用的标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 维护者还需要判断这个问题该怎么处理 |
| `needs-info` | `needs-info` | 信息不够，正在等待提交者补充 |
| `ready-for-agent` | `ready-for-agent` | 要求已经写清楚，可以交给 Agent 独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 已决定不处理 |

当技能提到某种状态时，要使用表中对应的实际标签。例如，技能要求添加“可交给 Agent 独立处理”的标签时，就使用 `ready-for-agent`。

如果仓库以后更换标签名称，只修改表格第二列即可。
