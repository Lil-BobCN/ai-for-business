This dataset contains the result of transforming the BPI Challenge 2019 event log from
Event Graph
format to Object-Centric Event Log (OCEL) format. The transformation is defined in the "Transforming Event Knowledge Graph to Object-Centric Event Logs: A Comparative Study for Multi-dimensional Process Analysis" paper.
