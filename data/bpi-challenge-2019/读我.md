# BPI Challenge 2019 采购数据

本目录用于逐步查看和分析 BPI Challenge 2019 的公开采购流程数据。

## 文件

- `raw/BPIC19-OCEL.zip`：4TU 发布的 OCEL 压缩包，许可 CC BY 4.0。
- `raw/BPIC19.jsonocel`：压缩包内完整 JSON OCEL，约 1.4 GB。注意：压缩包只有一个 JSON 文件，解压文件远大于压缩包。
- `raw/OCEL-README.txt`：OCEL 发布方说明。此 OCEL 是从原挑战事件图转换得到的版本，不是企业原始数据库，也不是最终企业 Ontology。
- `derived/ocel-sample.json`：为初学者查看制作的小样本，含原 OCEL 前 12 个事件及关联对象；不是完整数据，也不代表完整业务流程。
- `raw/BPI_Challenge_2019.xes.part`：原始 XES 下载未完成，当前文件不完整，不能用于分析。
- `raw/*-dataset-page.txt`、`raw/official-challenge-page.txt`：发布方网页的文本快照。

## 主要来源

- [BPI Challenge 2019 官方挑战说明](https://www.tf-pm.org/competitions-awards/bpi-challenge/2019)
- [4TU 原始 XES 数据页](https://data.4tu.nl/articles/dataset/BPI_Challenge_2019/12715853)
- [4TU OCEL 数据页](https://data.4tu.nl/datasets/46a7e15b-10c7-4ab2-988d-ee67d8ea515a)
- [OCEL 标准](https://ocel-standard.org)

## 许可与处理边界

OCEL 数据页标注 CC BY 4.0。引用和再分发时遵循署名条款。数据中的企业、供应商和标识均已匿名化；不要尝试反推真实主体。金额已匿名化转换，不应解释为真实货币金额。分析数据时区分“日志直接记录”“官方挑战说明提供的规则”和“我们自己的建模推断”。

## 当前已核对的数据规模

完整 OCEL 文件经流式检查：1,595,923 个事件，42 种活动；对象 330,685 个，包括 PO 76,349 个、POItem 251,734 个、Vendor 1,975 个、Resource 627 个。对象自身的 `ovmap` 均为空，业务属性主要存在事件 `vmap` 中。部分时间戳为 1948 年，和数据集主要业务时间范围不一致；在对照原始 XES 前，不用该版本的异常绝对日期做耗时结论。
